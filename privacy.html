Privacy Policy – Simply Unfolded Analytics

Last updated: 28 October 2026

Simply Unfolded Analytics is a private tool used only by the owner of the Simply Unfolded YouTube channel.

What data it accesses

With the owner's Google sign-in it reads, read-only, the YouTube Analytics and YouTube Data of the owner's own channel (for example views, watch time and audience retention). It does not access any other Google data.

How the data is used

The data is used only to write performance reports for the channel owner. It is not sold, shared with third parties or used for advertising.

Storage

Access tokens are kept privately by the owner. Reports stay with the owner. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
